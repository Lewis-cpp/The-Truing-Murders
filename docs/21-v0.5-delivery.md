## 与设计文档的差异

- 清空后的 `summary_json` 允许 SQL NULL 与 JSON `null` 两种空值（psycopg 为 None 绑定 JSON null）；
  两者都表示"无内容"，形状检查拒绝其余非法 JSON。
- 摘要条目的 token 按"条目正文字符数"估算（与 `estimate_tokens` 的字符口径一致），非分词器计数。
- `npc_memory_summary` 不建逐轮版本历史，只有当前一份（12 篇 6.2 的最小扩展）；写入竞态时
  条件更新失败方保留自己新算的摘要用于本轮，不重试写。
- `ThreadDispatcher.shutdown(wait=True)` 按规格补全默认 `wait=False` 的参数形态。
- lifespan 对嵌套重入（测试客户端共用同一 app）保持现有状态，顺序启动仍完整初始化。

## 已知限制

- 摘录式摘要只保留原文片段：寒暄、语气与被预算截掉的更早轮次会丢失；这是保守策略的既定代价，
  承认等核心事实每轮由授权内容重建，不依赖摘要。
- 本阶段之前创建的存档升级到 0005 后，旧轮次不带 epoch，不进入新上下文（玩家可见）；
  旧存档的自然语言记忆等效重置，结构化状态不受影响。
- 摘要缓存的并发写入按 `summary_revision` 乐观更新，失败方本轮用新算结果且不重试；
  同局并发生成由会话锁与部分唯一索引排除。
- `guard.json` 与案件/评分人工预期仍待真人复核（沿袭 v0.3/v0.4）。

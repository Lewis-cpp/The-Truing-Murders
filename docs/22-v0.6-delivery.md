## 与设计文档的差异

- `tests/e2e/conftest.py` 直接启动 `node_modules/.bin/vite preview` 而非 `npm run preview`：
  终止 npm 包装进程会孤儿化真正的 vite 服务，下一次运行因端口占用而失败（修订见
  test-amendments.md）。
- 引用联动（`cite-*`）通过 store 的请求队列把证据 ID 交给指控表单的本地草稿，
  表单状态不整体上移到 store。
- `frontend/tests/interrogation.test.ts` 三处测试的驱动方式从被替换的 v0.3 实现细节
  （出示下拉、重启 Popconfirm 的组件实例）迁移到新的 `data-testid` 契约，业务断言不变
  （test-amendments.md 第 2 条）。
- pytest 切换 `--import-mode=importlib` + `pythonpath=["tests"]`：e2e 的 conftest 在 prepend
  模式下会遮蔽根 conftest，使全套件收集失败（提交 6753933）。

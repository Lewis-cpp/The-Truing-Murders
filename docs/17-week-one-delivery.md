## 已确认的决策

- 《停电之夜》发生在研究所；负责人陆衡遇害，沈砚为掩盖实验造假行凶。用户授权补齐细节。
- 凶手选错直接判错；凶手正确后累计其他项目。证据要明确引用并关联步骤。
- 无招供可满分；全猜对但没有证据最多75分、部分正确。解释文字不参与评分。
- 正确阈值85，部分正确阈值30；过程严格比对完整顺序。阈值具体值属于本次配置草稿。
- 85分「正确」表示达到阈值，不表示所有分项都正确；例如顺序错失15分、其余全对仍可达85，复盘必须显示该失分。
- W1 只承认到场，不等同杀人招供。完整犯罪承认属于草稿中的下一层。
- 运行时不开发或使用 Agent，不调用模型，不需要模型密钥和数据库。

## 实现与权限边界

领域数据及固定契约放在 `backend/src/backend/domain/models.py`，阶段与情绪在 `state_machine.py`，
证据引用和白名单投影在 `evidence.py`，纯规则计算在 `rules.py`。
`application/case.py` 校验并载入案件，`application/game.py` 维护一局内存状态，
`cli.py` 只接收玩家输入并调用实际用例。复用已有 Pydantic，不增加新第三方库。

沿用九阶段名称，INIT／INTRO／JUDGEMENT 为概念上的内部瞬态，外部只看到完成初始化或结案的快照。
本周深入调查标记仅由谎言击破触发；没有额外深入场景。返回调查保留该标记。
普通提问和读取不增版本、不运行规则；有效变更增加一次版本，完全重复动作不增加。
拒绝操作不消费效果、不发证据、不结束游戏。结案不重跑调查规则。

玩家投影只提供公开案情、合法候选、已获得物证与已披露证词。
NPC固定说法投影仅提供当前说法、自己有权披露的条目、实际向其出示的物证。
这不是 Agent 上下文实现；不存在模型客户端、提示词调用或对话生成任务。
完整真相只在正式结案后对玩家投影开放。结案后读复盘不修改冻结的调查输入。
本地作者当然能查看案件资源文件；CLI不提供对本机文件所有者保密的安全边界。

切片资源仅打包到后端，前端公开目录为 `frontend/public/`。
现有 Vue 页面仍是基础工程检查页，没有把案件答案嵌入网页。
